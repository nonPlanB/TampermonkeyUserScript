## 项目背景与脚本列表

本项目基于现有用户脚本进行整理和兼容修订，解决日常浏览中英文界面理解、页面元素干扰、视频播放和内容筛选等问题。脚本通过 Tampermonkey 在匹配的网站运行，无需启动后端服务，也无需执行构建命令。

两个脚本相互独立，可只安装需要的一个。以下说明对应仓库当前源码，功能是否生效还取决于目标网站的页面结构、接口和浏览器环境。

| 脚本 | 当前源码版本 | 主要用途 | 匹配范围 |
| --- | --- | --- | --- |
| [GitHub汉化.js](./GitHub汉化.js) | `2.0.0-local.20261105` | 内置简体中文词库、动态界面翻译、手动翻译简介 | `https://github.com/*`、`https://gist.github.com/*`、`https://skills.github.com/*`、`https://education.github.com/*`、`https://www.githubstatus.com/*` |
| [抖音美化.js](./抖音美化.js) | `2025.10.5` | 界面精简、视频过滤、画质与全屏设置、直播优化、移动分享页适配 | `*://*.douyin.com/*`、`*://*.iesdouyin.com/*` |

> 抖音脚本包含桌面页面和移动分享页的不同配置。桌面浏览器可以运行脚本，并不代表所有移动浏览器都支持 Tampermonkey；移动端需使用支持相应扩展的浏览器，具体功能以实际页面为准。

## 安装与配置

### 1. 安装 Tampermonkey 扩展

1. 使用准备运行脚本的浏览器打开 [Tampermonkey 官网](https://www.tampermonkey.net/)。
2. 选择对应浏览器，通过官网提供的入口进入官方扩展商店。
3. 在商店中点击安装按钮，并确认扩展所需权限：

   | 浏览器 | 安装入口与操作 |
   | --- | --- |
   | Chrome | 从官网选择 Chrome，进入 Chrome 网上应用店，点击“添加至 Chrome” |
   | Microsoft Edge | 从官网选择 Edge，进入 Microsoft Edge 加载项商店，点击“获取”并添加扩展 |
   | Firefox | 从官网选择 Firefox，进入 Firefox 附加组件页面，点击“添加到 Firefox” |
   | Safari | 从官网选择 Safari，按对应 App Store 页面安装，并在 Safari 设置中启用扩展、授予目标网站访问权限；可用版本和费用以商店为准 |

4. 打开浏览器的扩展管理菜单，将 Tampermonkey 固定到工具栏，方便查看脚本状态。
5. 在扩展详情中确认扩展已启用，并允许它访问你要使用脚本的网站。

Chrome/Edge 等 Chromium 浏览器还可能要求单独开启用户脚本执行权限。进入 `chrome://extensions` 或 `edge://extensions`，打开 Tampermonkey 的详情页；若有“允许运行用户脚本 / Allow User Scripts”选项，请开启。没有该选项时，按浏览器和 Tampermonkey 提示开启扩展管理页的“开发者模式”，再刷新目标网页。参见 [Tampermonkey 官方执行权限说明](https://www.tampermonkey.net/faq.php?q=Q209)。

### 2. 新建脚本并粘贴源码（推荐）

仓库文件以 `.js` 结尾，点击后可能仅显示源码，不一定自动打开油猴安装页。使用新建脚本的方式即可安装。

1. 打开[本项目仓库](https://github.com/nonPlanB/TampermonkeyUserScript)，选择 `GitHub汉化.js` 或 `抖音美化.js`。
2. 点击文件页面的 **Raw / 原始文件**，复制完整源码。必须包含开头的 `// ==UserScript==` 元数据区和文件末尾的代码；不要复制 GitHub 网页的 HTML。
3. 点击工具栏中的 Tampermonkey 图标，选择“添加新脚本 / 创建新脚本”；也可以进入“管理面板”，通过加号新建。
4. 在编辑器中按 `Ctrl+A` 全选默认模板，粘贴刚才复制的源码，完整替换模板。
5. 按 `Ctrl+S` 保存；macOS 使用 `Command+S`。也可使用编辑器菜单中的保存命令。
6. 返回 Tampermonkey 管理面板，确认出现对应脚本名称，且开关处于启用状态。
7. 如需另一个脚本，重复上述步骤，新建另一条脚本。**不要把两个文件拼接到同一个编辑器中。**
8. 打开匹配的网站并刷新。在目标网页点击 Tampermonkey 图标，确认脚本已运行。

该流程也可参考 [Tampermonkey 官方脚本安装说明](https://www.tampermonkey.net/faq.php?q=Q102)。

### 3. 从本地文件导入

1. 在 GitHub 仓库页面通过 **Code → Download ZIP** 下载并解压，或运行：

   ```bash
   git clone https://github.com/nonPlanB/TampermonkeyUserScript.git
   cd TampermonkeyUserScript
   ```

2. 使用支持 UTF-8 的文本编辑器打开所需 `.js` 文件。
3. 按上一节的方法，将完整源码粘贴到 Tampermonkey 新建的脚本中并保存。
4. 如果当前 Tampermonkey 版本的“实用工具 / 导入”页面支持脚本文件导入，也可以选择本地文件，检查预览后确认安装。若文件无法识别，使用复制源码的方式。

导入功能和备份格式可参考 [Tampermonkey 官方管理说明](https://www.tampermonkey.net/faq.php?q=Q101)。

### 4. 首次运行与基本配置

1. GitHub 脚本：访问匹配的 GitHub 页面，刷新后检查导航菜单、按钮等是否出现中文。
2. 抖音脚本：访问[抖音网页版](https://www.douyin.com/)，点击 Tampermonkey 图标，在“抖音美化”下选择 **⚙ 设置**。
3. 使用移动分享页时，通过 **⚙ 移动端设置** 打开独立配置面板。
4. 每次先调整少量选项，再刷新页面确认效果。部分样式可以立即更新，初始化、网络拦截和播放器相关选项建议刷新后验证。

配置保存在当前浏览器配置文件的 Tampermonkey 脚本存储中。更换浏览器或设备时，需要单独备份、导入或使用 Tampermonkey 的同步功能。

## GitHub 汉化使用说明

### 自动翻译界面

安装并启用后，访问匹配网站即可自动工作，不需要另外下载词库。覆盖内容包括导航、菜单、按钮、提示、部分表单占位文字和无障碍标签，以及词库已收录的页面标题。

词库包含仓库、Issue、Pull Request、Actions、设置、个人和组织页面等常见场景，并提供 Gist、Skills、Education 和 GitHub Status 的相应词条。未收录的英文会保留，不能保证所有页面完全汉化。

### 动态页面与时间显示

1. 正常打开下拉菜单、弹窗，或在 GitHub 内切换仓库标签页。
2. 脚本会监测新加载的内容和页面导航，继续应用对应页面的词条。
3. 匹配的相对时间、日期组件会尝试显示中文。
4. 如果界面有遗漏，在 Tampermonkey 的脚本菜单中点击“重新翻译当前页面”；仍无变化时刷新页面。

该菜单会重新扫描当前页面，不能为词库中不存在的内容生成译文。

### 正则翻译开关

正则翻译默认开启，用于处理包含数量等变化内容的界面文字。

1. 打开目标网页上的 Tampermonkey 菜单。
2. 在 GitHub 汉化的菜单中选择“关闭正则翻译（刷新生效）”或“开启正则翻译（刷新生效）”。
3. 脚本会保存选择并自动刷新页面。

关闭后，普通固定词条仍然工作；部分动态文字可能恢复英文。时间组件有独立的本地化处理，不完全受该开关控制。

### 手动翻译仓库或 Gist 简介

1. 打开仓库首页或 Gist 页面，找到英文简介。
2. 若简介区域符合脚本的识别规则，会出现“翻译简介”按钮。
3. 点击按钮后等待请求完成，中文结果显示在简介下方，原文保留。
4. 失败时点击“翻译失败，点击重试”；需要再次请求时点击“重新翻译简介”。

**只有主动点击按钮时，脚本才会将该简介文本发送至讯飞听见翻译服务 `fanyi.iflyrec.com`。** 不希望向外部服务发送的文本请勿点击翻译。接口不可用、跨域请求被阻止或简介区域变化都可能导致翻译失败。

### 内容保留与注意事项

脚本针对网站界面进行词条匹配，并对代码块、README/Markdown 正文、评论、编辑区域、文件名、用户名和仓库名等设置保护规则。这些内容通常保留原文；仓库和 Gist 简介通过前述按钮手动翻译。

同时开启其他 GitHub 汉化脚本或浏览器整页翻译可能产生重复替换。遇到界面异常，可先禁用其他翻译工具并刷新。本脚本的匹配范围不包含自建 GitHub Enterprise 域名。

### 视频过滤器与规则配置

入口：**视频 → 过滤器**。该功能通过处理视频数据，按规则过滤广告、直播或其他不想看的内容。

1. 确认过滤器“启用”已打开，默认开启。
2. 点击“视频过滤规则 → 自定义”，在规则管理窗口中新增规则。
3. 填写规则名称，开启该规则，并选择作用域，例如所有、精选、推荐、关注、朋友、搜索、用户主页、混合信息或相关推荐。
4. 选择属性名并填写属性值。字符串可使用正则表达式；布尔字段使用 `true` 或 `false`；数值比较按字段和规则解析方式填写。
5. 保存规则，刷新目标页面并检查新加载的视频。

常见规则示例（每行单独创建一条规则，关闭“是否使用自定义函数处理”）：

| 目标 | 属性名 | 属性值示例 |
| --- | --- | --- |
| 过滤被识别为广告的视频 | `isAds` | `true` |
| 过滤直播条目 | `isLive` | `true` |
| 按作者昵称过滤 | `nickname` | `示例昵称` |
| 按文案关键词过滤 | `desc` | `关键词甲\|关键词乙` |

以上示例用于说明字段用法，不代表安装后已预置这些规则。过滤依赖接口提供相应字段，不能保证识别所有广告或直播。

规则还支持视频 ID、作者 UID、话题标签、音乐信息、认证信息、风险提示、短剧/合集信息、点赞和评论等统计、时长、直播间信息、码率及商品信息等属性，具体以“属性名”列表为准。可添加额外属性组合条件，也可启用自定义函数处理；函数需要返回布尔值，仅建议在理解代码含义后使用。

- **查看视频数据**：保持“新增 {...} 按钮”开启，在视频底部工具栏点击 `{...}`，查看实际字段，再编写规则。
- **检查命中情况**：“仅显示被过滤的视频”会反转显示逻辑，只展示命中的内容；平时应关闭，避免误以为正常视频都被过滤。
- **管理规则**：在规则窗口启用、停用、编辑或删除规则，并按启用状态筛选。清空操作前先导出备份。
- **导入导出**：在过滤器页面使用“数据导出”保存 JSON，通过“数据导入”恢复规则。该文件用于视频过滤规则，不等同于完整脚本配置备份。

### 快捷键设置

脚本同时提供“自定义快捷键”和“禁用抖音快捷键”，两者用途不同。

1. 在 **视频 → 自定义快捷键** 中，可为倍速减小、倍速增大、沉浸模式和切换静音录入按键。
2. 在 **直播 → 自定义快捷键** 中，可为屏蔽聊天室、屏蔽礼物特效和切换静音录入按键。
3. 点击“点击录入快捷键”，按面板提示输入需要的组合键，完成后返回视频或直播页面测试。
4. 在 **通用 / 视频 / 直播 → 禁用抖音快捷键** 中，开启某项表示拦截网站原有按键。它不会为该功能新增快捷键。

可拦截的常见按键包括点赞 `Z`、评论 `X`、弹幕 `B`、收藏 `C`、分享 `V`、清屏 `J`、连播 `K`、网页全屏 `Y`、全屏 `H`、空格暂停和方向键等；视频分类另有 `W/S/A/D`，直播分类另有刷新 `E`、旋转 `D`、小窗 `U` 和方向键切换直播间。完整列表与其他按键说明见设置面板。

不要将自定义按键与常用浏览器快捷键冲突绑定；需要恢复网站默认按键时，关闭对应的禁用开关。

## 权限与外部依赖

| 脚本 | 使用的能力 | 外部访问 |

## 更新、备份与卸载

### 更新

1. 在[本项目仓库](https://github.com/nonPlanB/TampermonkeyUserScript)检查文件变化，或在本地执行 `git pull` 获取更新。
2. 更新前，通过 Tampermonkey 的实用工具导出脚本及设置；视频过滤规则也可单独导出 JSON。
3. 在管理面板中打开**已有的对应脚本**，用新版完整源码替换并保存，避免重复安装多份。
4. 刷新目标网页，检查菜单、主要功能和配置是否正常。

两个脚本当前均未配置指向本仓库的 `@updateURL` / `@downloadURL`，本文的手动安装方式不保证自动更新。本次调整过脚本命名空间；已安装旧版本的用户建议在原脚本条目中替换源码，并提前备份，避免新建条目导致旧配置未被沿用。

### 停用与卸载

- 临时停用：在 Tampermonkey 管理面板关闭对应脚本，再刷新目标网站。
- 卸载脚本：先导出需要的配置，再在管理面板删除对应脚本，刷新页面。
- 卸载扩展：在浏览器扩展管理页移除 Tampermonkey；移除前先备份其他脚本和设置。

## 常见问题

| 问题 | 排查方法 |
| --- | --- |
| 安装后没有任何效果 | 确认扩展与脚本均已启用、当前网址匹配、网站访问权限已授予；Chrome/Edge 检查用户脚本执行权限，完成后刷新 |
| 点击仓库脚本只看到代码 | 当前文件名为 `.js`，按“新建脚本并粘贴源码”安装即可 |
| 菜单里没有抖音设置 | 在匹配的抖音页面打开菜单；检查外部依赖是否下载成功，脚本是否报错 |
| GitHub 仍有部分英文 | 先尝试“重新翻译当前页面”；未收录词条和受保护的用户内容会保留原文，动态文本还可检查正则翻译开关 |
| 简介翻译失败 | 检查外部请求授权和网络；服务接口可能变化，失败不影响内置词库翻译 |
| 抖音按钮或导航不见了 | 检查对应“布局屏蔽”和沉浸模式，关闭相关选项后刷新；搜索页还可能有单独配置 |
| 过滤器过滤过多或完全无效 | 检查总开关、规则启用状态、作用域、属性类型与正则；关闭“仅显示被过滤的视频”，通过 `{...}` 查看字段 |
| 选择 4K 后画质没有变化 | 视频可能没有对应清晰度，或网站接口、登录状态限制了可用资源 |
| 下载失败 | 检查 Tampermonkey 下载权限、浏览器下载提示及资源可访问性，确认视频解析已开启 |
| 页面异常或明显变慢 | 暂停其他同类脚本和整页翻译扩展，逐项关闭可疑功能并刷新；网站更新也可能使规则失效 |
| 换浏览器后配置丢失 | 配置属于原浏览器的脚本存储，需要从备份导入或事先配置同步 |

如需反馈，请在 [Issues](https://github.com/nonPlanB/TampermonkeyUserScript/issues) 提供脚本名与版本、浏览器及 Tampermonkey 版本、页面类型、复现步骤、预期与实际结果。可附去除敏感信息的截图和控制台错误；请勿提交 Cookie、令牌或私人页面内容。
